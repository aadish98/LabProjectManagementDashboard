# Privacy Policy

Last updated: April 24, 2026

Lab Project Management Dashboard is a desktop application for managing lab workflow data stored in Google Sheets. This policy explains what information the application accesses, how it is used, and how users can control it.

## Information We Access

The application uses Google sign-in and may request access to:

- Your Google account profile information, such as your name and email address, to identify the signed-in user and determine whether the user has manager or employee access.
- Google Sheets files that your Google account is authorized to access, including task logs, compliance records, feedback records, and related workflow spreadsheets.
- Spreadsheet metadata, such as sheet names and spreadsheet titles, so the application can find the correct worksheet tabs.

The application only accesses Google Sheets data needed to provide the workflow features shown in the app.

## How We Use Information

Information accessed through Google APIs is used to:

- Sign users in and identify their role.
- Display lab task logs, dashboards, compliance summaries, feedback, and related workflow views.
- Create, update, or organize task-log records at the user's request.
- Validate spreadsheet setup and show helpful error messages when required sheets or columns are missing.

Google user data is not used for advertising, unrelated analytics, or profiling.

## Data Storage

The application does not operate a separate backend server for storing Google user data.

Workflow data remains in the Google Sheets files controlled by the user or the user's organization. Some setup preferences, such as selected spreadsheet URLs, sheet names, or role configuration, may be stored locally on the user's device so the app can reopen with the same settings.

## Data Sharing

The application does not sell, rent, or share Google user data with third parties.

Data may be visible to other people only through the user's existing Google Drive or Google Sheets sharing settings. Users and administrators are responsible for managing access to their spreadsheets in Google Drive.

## Google API Limited Use

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Data Retention and Deletion

Because workflow data is stored in Google Sheets, users can delete or modify that data directly in the relevant spreadsheet.

Users can also revoke the application's Google access at any time from their Google Account permissions page:

https://myaccount.google.com/permissions

Locally stored application preferences can be removed by clearing the application's local data on the user's device or uninstalling the application.

## Security

The application uses Google's OAuth flow for authentication and authorization. Google access tokens are used to make authorized requests to Google APIs during the user's session.

Users should only sign in on devices they trust and should manage spreadsheet sharing permissions carefully in Google Drive.
